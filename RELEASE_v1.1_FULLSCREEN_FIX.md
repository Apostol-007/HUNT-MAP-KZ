# HUNT MAP KZ v1.1 — исправление полноэкранной карты

## Причина дефекта

Раньше `OfflineMapView` был вложен во вкладку системного `TabView`, а `.ignoresSafeArea(edges: .top)` расширял его только вверх в рамках текущей компоновки. На реальном iPhone на скриншоте наблюдались большие чёрные области над картой и под системной панелью вкладок.

## Исправление

- `MainView.body` больше не содержит системный `TabView`.
- Вместо него используется корневой `ZStack` с переключением пяти разделов.
- Для карты `OfflineMapView` занимает всю область `GeometryReader`, а карта игнорирует safe area по всем краям.
- Панель разделов находится в `.overlay(alignment: .bottom)` и не отнимает у карты высоту.
- Три полевые кнопки помещены над плавающей панелью разделов.
- GPS, записи, каталоги, загрузки и диагностика не удалены.

## Проверено в среде разработки

- Swift Package: 14 XCTest + 8 Swift Testing, 0 ошибок.
- FastAPI: 24 теста, 0 ошибок.
- Структура MainView проверена: системный TabView удалён; карта расширяется на все safe-area.

## НЕ проверено

- Не производилась компиляция iOS-таргета в Xcode, нет скриншота исполнения на физическом iPhone.
- Визуальная и функциональная регрессия UIKit/MapLibre ещё требует реальной установки IPA.
- Результат не должен считаться подтверждённым исправлением для всех размеров iPhone до полевого теста.

## Как получить сборку

1. Загрузить содержимое архива в корень GitHub-репозитория (включая `.github`).
2. Запустить `Actions → iOS unsigned IPA → Run workflow`.
3. Если сборка не проходит, открыть артефакт `ios-build-log`, исправить ошибку сборки и повторить.
4. Если сборка успешна, скачать `HUNT-MAP-KZ-unsigned-IPA`; для установки нужна подпись, unsigned IPA на iPhone напрямую не ставится.
5. После установки сделать скриншот карты: под часами и нижним индикатором должна быть видна карта, а не чёрная заливка.

## Граница изменений

Релиз v1.1 исправляет геометрию отображения главного экрана, **не подтверждает** прямую интеграцию официальных слоёв Tabigat, спутниковые снимки 1 м/пиксель и полноту базы животных.
