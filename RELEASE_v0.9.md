# HUNT MAP KZ 0.9 — отчёт о готовности

Дата: 19 ноября 2026.

## Фактическая работа

- Заменена пустая схема по умолчанию на MapLibre + онлайн-стиль OpenFreeMap по явному переключателю. Строгий офлайн-стиль сохраняется, MBTiles остаются локальными.
- Исправлен опасный сценарий включения `allowsBackgroundLocationUpdates`: только после авторизации «Всегда». Раньше включался без проверки разрешений, что могло приводить к аварийному завершению. Точный crash log исходного iPhone не предоставлен, поэтому причинная связь предварительная.
- Добавлены сообщения об отказе GPS и явный запрос фонового разрешения.
- Добавлена загрузка опубликованного GeoJSON с настроенного HTTPS API. Реальных официальных национальных границ в проекте нет.
- Добавлен агрегированный запрос к публичному GBIF по стране KZ (до 100 научных названий). Не выдаёт перечень по угодью или разрешение на добычу; точные координаты не сохраняются.
- Добавлена диагностика с текстовым экспортом и обработкой shake через UIKit responder. Сведения о маршрутах и точных координатах скрыты.
- О приложении: имя, город, профессиональная роль инициатора и источники данных.
- `.github/workflows/ios-unsigned.yml`: сборка unsigned IPA в GitHub Actions на macOS runner; `.github/workflows/quality.yml`: тесты.

## Доступные проверки

- `python -m pytest server/tests -q` — **24 passed**.
- `swift test --package-path Core` — тесты ядра **успешны** (12 XCTest + 8 Swift Testing по существующим тестам; проверить актуальный вывод тест-раннера).
- `swiftc -frontend -parse iOS/HuntMap/*.swift` — синтаксический разбор исходников (не полноценная проверка типов и API iOS).

## НЕ ПРОВЕРЕНО

- `xcodegen generate`, полная компиляция iOS и запуск на физическом iPhone. Здесь нет Xcode/iOS SDK.
- Фактическое отображение онлайн/MBTiles в MapLibre на устройстве; возможны несовместимости версий SDK.
- Shake gesture при запущенном UI и фоне, работа Share Sheet с ChatGPT.
- Отсутствие crash после нажатия «Запись» на конкретном iPhone; нужен исходный crash report.
- Сетевая доступность OpenFreeMap/GBIF и геоданных в реальной сети; API может менять условия.
- Реальное покрытие юридических границ, спутниковые снимки 1 м, офлайн-пакеты регионов, массовые обновления видов.
