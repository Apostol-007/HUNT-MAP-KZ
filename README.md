# HUNT MAP KZ — исходный проект (проверка компиляции)

SwiftUI + MapLibre (iOS 17+), Swift Package `Core`, сервер FastAPI и инструменты подготовки карт.
Все элементы интерфейса и приоритет картографических подписей — на русском, когда данные содержат `name:ru`.

## Сборка IPA на Windows

1. Скопировать **содержимое этого ZIP**, включая `.github/`, в корень репозитория GitHub.
2. Открыть **Actions → HUNT MAP KZ - unsigned iOS IPA → Run workflow**.
3. Дождаться успешного завершения **обоих** заданий: Swift/server tests и Compile iOS.
4. Скачать артефакт `HUNT_MAP_KZ_unsigned_IPA`. Это **неподписанная** сборка; для установки нужна подпись.

Полная инструкция: [`docs/GITHUB_IPA_WINDOWS_RU.md`](docs/GITHUB_IPA_WINDOWS_RU.md).

## Как проверить исходники локально

```bash
swift test --package-path Core
python -m pip install -r server/requirements.txt pytest httpx
python -m pytest -q server/tests
```

Для Xcode: `cd iOS && xcodegen generate --spec project.yml`, открыть `HuntMapKZ.xcodeproj`.

## Функции и ограничения

- Главная карта MapLibre, GPS, маршруты, маркеры, границы, офлайн MBTiles, погода.
- Серверные пакеты MBTiles устанавливаются через API `/v1/packs/manifest` и `/v1/packs/{id}`. **Статический JSON-каталог собственного хостинга пока несовместим с этим клиентом**; его файлы сохранены в `hosting_upload/` для отдельной интеграции.
- `maps/` и `hosting_upload/` — полезные небольшие тестовые картографические пакеты, не подтверждённые официальные границы охотугодий.
- Для погодных сеток нужен отдельный запущенный HTTPS-сервер; без него доступны лишь функции точечной погоды.
- Отсутствует проверка полноценной iOS-компиляции и полевых функций на физическом устройстве после внесённых правок. Исправления базируются на конкретных ошибках предыдущего CI-лога, но могут обнаружиться последующие ошибки.
- Не использовать неподтверждённые границы для юридических решений об охоте.

## Что исправлено в этом архиве

1. `Marker` получил необязательные поля `symbol`/`colorHex`, чтобы редактор и дальномер использовали одну модель без потери старых данных.
2. Экран загрузки карт разбит на небольшие SwiftUI-компоненты, чтобы сократить время проверки типов компилятором.
3. Удалены обращения к несуществовавшим `staticCatalogURL/staticPacks/installStaticPack` в `OfflineTileStore`; заменены реально существующим серверным API.
4. Удалены только исторические дубли файлов, вложенный старый ZIP, копии релизов и логи. Реальные модули `Core/`, `iOS/`, `server/`, `tools/`, `scripts/`, `maps/`, `hosting_upload/`, тесты и `.github/` сохранены.

Полный перечень удаления: [`docs/CLEANUP_REPORT.md`](docs/CLEANUP_REPORT.md).
