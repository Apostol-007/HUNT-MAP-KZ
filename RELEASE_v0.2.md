# HUNT MAP KZ v0.2 — результаты
Дата: 2026-11-19

## Выполнено
- Режимы выбора масштаба: область, охотугодье, Казахстан (поиск манифестов, не готовые данные).
- Локальный реестр пакетов и интерфейс удаления без влияния на маршруты и маркеры.
- Загрузка raster MBTiles с сервера HTTPS (URLSession), проверка SHA-256, отбраковка неподдерживаемого формата.
- Открытие локальных MBTiles через SQLite3 и MapKit; конверсия XYZ в TMS; локальные границы и треки как оверлеи.
- CLI для публикации заранее полученного MBTiles, метаданные лицензии, SHA-256, версионирование ID.

## Тесты текущей среды
- SwiftPM HuntCore: 8/8 пройдены в Linux Swift 6.2.1.
- pytest FastAPI: 4/4 пройдены, включая публикацию тестовой SQLite MBTiles и частичные HTTP-ответы.
- SwiftUI/iOS/MapKit/CryptoKit: сборка НЕ выполнялась, macOS/Xcode отсутствуют.
- iPhone, фон, AirDrop, фактические GPS-треки: НЕ проверены.

## Требует доработки
- Полное соблюдение strict offline на MapKit, замена на MapLibre при необходимости.
- Хранение тайлов с дедупликацией между пакетами и resumable downloads.
- Оптимизация повторного хеширования больших пакетов (сейчас потоковая SHA-256 при каждом скачивании).
- Публикация лицензированных карт, реестр охотугодий, OSM trail layers, каталог животных.
- Клиентская проверка подписанного манифеста, защита от недоверенного сервера.
- Запуск и тесты на реальном iPhone.
