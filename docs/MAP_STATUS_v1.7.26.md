# HUNT MAP KZ 1.7.26 — карта и слои

## Исправлено
- При перезагрузке стиля MapLibre повторно добавляются OSM-линии и сетка покрытия, которые могли исчезать после переключения оформления.
- Инвалидация OSM-слоя учитывает фактический набор линий, а не только revision.
- Уточнена документация: наличие MBTiles на диске **не означает**, что MapLibre Native поддерживает `mbtiles://` и действительно отрисовал карту.

## Не реализовано / требует проверки
- Полноценная локальная векторная карта Казахстана из GIS-Lab / Geofabrik.
- Подтверждённый работающий offline tile provider для MapLibre iOS (нельзя полагаться на `mbtiles://` без испытания).
- Реальная загрузка спутниковой подложки, рельефа и офлайн-карт всей страны.
- Полная сборка Xcode и тест на физическом iPhone.

## Проверки
- Swift frontend parse всех Swift-файлов приложения: пройден.
- Swift package tests (Core): 11 тестов пройдено.

Это промежуточное исправление отображения слоёв, а не готовая замена 2GIS.
