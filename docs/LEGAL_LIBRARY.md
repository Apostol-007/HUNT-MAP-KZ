## Пользовательский интерфейс

- Поиск по всем четырём документам: результаты с номерами страниц.
- Поиск внутри документа с переходами к странице.
- PDFKit: сохранение исходного оформления и таблиц, свайп и pinch zoom, масштабирование кнопками.
- Все PDF входят в IPA и читаются без сети.
- Указание номера, даты, объёма и исходной редакции; приложение не объявляет документы актуальными без юридической проверки.
- Для обновления текста требуется заменить файл в `iOS/HuntMap/LegalDocuments/` и собрать приложение.

## Сборка

Папка `LegalDocuments` должна копироваться в bundle приложения как ресурсы. При сборке проверять наличие всех четырёх PDF через `Bundle.main.url(forResource:withExtension:subdirectory:)` и запасной поиск в корне bundle.
