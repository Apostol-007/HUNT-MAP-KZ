# HUNT MAP KZ — выпуск исходников 2.4.0 (23.11.2026)

## Реализовано в исходниках

- Погодные заливки рассчитываются билинейной интерполяцией внутри каждой ячейки 4×4 прогностической сетки, без выхода за границу валидированных данных. По 3×3 подячейки для ветра/давления, по 4×4 для осадков.
- По ветру рисуются стрелки, направленные **куда дует**, с корректным преобразованием направления метеомодели «откуда дует».
- По давлению строятся сегменты изобар с шагом 5 гПа алгоритмом marching squares. В сомнительных седловых случаях линии не объединяются искусственно. Сетка 4×4 даёт грубые, ориентировочные линии.
- Прогнозные осадки представлены цветовой интерполяцией в пределах проверенной сетки, **не радиолокационными наблюдениями**.
- Сохранены +0…48 часов выбора прогноза, русский интерфейс/названия на карте, локальный кэш и указание источника.
- GitHub Actions и verify_iphone_layout.py проверяют версию 2.4.0.

## Автоматические тесты в текущей среде

- `cd Core && swift test`: 24 XCTest + 8 Swift Testing, без ошибок (Linux Swift 6).
- `python -m pytest server/tests -q`: 31/31, успешно.
- `python scripts/verify_iphone_layout.py`: проверка исходников и конфигурации.

## Не проверено / не готово

- Xcode, MapLibre UI, визуальный рендеринг полилиний, IPA и физический iPhone — не проверены; возможны ошибки компиляции/отрисовки на iOS.
- Нет реальной пространственной интерполяции по высокоразрешённой метеомодели: имеющаяся сетка всего 4×4; изобары приближённые.
- Нет анимации частиц ветра и smooth playback кадров погоды.
- Нужен работающий пользовательский HTTPS FastAPI сервер для погодной сетки. Исходные данные предоставляются Open-Meteo, применяются условия его лицензии и тарифов.
- Прямое автоматическое получение официальных границ Tabigat не подтверждено. Импорт законно полученного GeoJSON остаётся доступен.
- Полноэкранность карты и фоновые GPS-функции требуют реальных полевых испытаний, приложения нельзя использовать как единственный источник навигационной безопасности и юридических границ.

## Сборка

Содержимое архива загрузить **в корень репозитория** GitHub (включая `.github`). `Actions → iOS unsigned IPA → Run workflow`. После зелёной сборки скачать артефакт, подписать отдельно; unsigned IPA напрямую не устанавливается.
