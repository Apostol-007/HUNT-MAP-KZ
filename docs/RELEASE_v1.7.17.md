# HUNT MAP KZ 1.7.17 — маркеры и диагностика загрузки

## Изменения
- Маркеры теперь рисуются поверх MapLibre как UIKit-изображения фиксированного размера (42 pt) и перепозиционируются при изменении камеры. Они не зависят от правил коллизий подписей, масштаба тайлов и загрузки стиля. Если координата маркера вне текущей видимой области карты, маркер не показывается — это нормальное поведение карты.
- Нажатие в радиусе 36 pt и перенос долгим нажатием сохранены. Редактор значка, цвета, координат и удаление сохранены.
- Для Overpass добавлен официальный сервер overpass-api.de, затем два резервных. При каждом ответе сохраняются HTTP-код, имя сервера и причина ошибки; проверяется наличие JSON `elements` и `remark`.
- На экране загрузки ошибки видны красным и доступны для копирования/отправки. В диагностическом отчёте теперь есть статус и ошибка OSM-загрузки.

## Ограничения
- Overpass загружает только дороги, тропы и водотоки в выбранном радиусе. Это **не полноценная офлайн-картографическая подложка**.
- Доступность публичных Overpass API зависит от сети, нагрузки и ограничений операторов. Тестов реальной загрузки с iPhone и полной Xcode-сборки в этой среде нет.
- Карты MBTiles импортируются отдельно; прямой загрузки полноценной карты Казахстана одной кнопкой из Geofabrik/BBBike эта версия не добавляет.
