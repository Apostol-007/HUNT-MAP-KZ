# HUNT MAP KZ 2.2.0 — погодные слои на карте

## Изменения в исходниках

- `WeatherGridService.swift`: декодирование/валидация сетки, загрузка с настроенного HTTPS-сервера, 3×3 точки, кеш последнего ответа, запрет сетевых запросов в строгом офлайн-режиме, сообщение об ошибке.
- `WeatherMapSheet.swift`: выбор одного цветового слоя — «Ветер», «Давление», «Осадки», выбор часа прогноза от 0 до +48 ч; URL сервера вручную, кнопка обновления.
- `OfflineMapView.swift`: 2×2 полупрозрачные MLNPolygon поверх базовой карты; цвет = среднее четырёх валидных угловых значений, пропуски не закрашиваются, за границами сетки ничего не рисуется.
- `MainView.swift`: кнопка включения погодных слоёв в меню карты; индикатор активного слоя и кеша, карта сохраняется на весь экран, русские подписи сохранены.
- `project.yml`: маркетинговая версия 2.2.0, номер сборки 22.

## Где взять прогноз для карты

Запусти сервер из `server/` согласно README на собственном HTTPS-хостинге. В «Слои → Погодные слои» укажи **базовый URL сервера**: например, `https://your-host.example`. Клиент запросит `GET /v1/weather/grid?bbox=...&at=...&steps=3`. Сервер обращается к Open-Meteo только в допустимых лимитах и выдаёт выборку узлов.

**Ограничения:** не деплоено и не тестировалось на реальном iPhone. Прогноз точек по сетке (базовая демонстрация), **не метеорадар и не полноценная непрерывная heatmap**. Пока нет анимации частиц ветра, изобар, автоматической подгрузки по видимой области, синхронизации времени карты с погодной карточкой и полноценного кеширования на сервере. Не использовать как единственный источник решения о погодной безопасности.
