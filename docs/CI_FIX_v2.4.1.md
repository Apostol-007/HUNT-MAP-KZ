# HUNT MAP KZ v2.4.1 — GitHub Actions hotfix

## Исходная ошибка

GitHub Actions (commit `f3bd710ace877c4d900d59b63f409f4630ea073c`, 23.11.2026):
`server/tests/test_point_packs.py::test_point_catalog_uses_mbtiles_bounds` завершался `TypeError: string indices must be integers, not 'str'`.

В ранее переданном архиве v2.4 маршрут `GET /v1/packs/at-point` отсутствовал. В репозитории GitHub присутствовал новый тест, ожидающий ответ в формате JSON-массива с `pack_id`. Это несоответствие устраняется **реализацией маршрута**, а не удалением теста.

## Изменения

- Добавлен `GET /v1/packs/at-point?lat=...&lon=...` в `server/app.py` **до** динамического `/v1/packs/{pack_id}`.
- При поиске читается `metadata.bounds` из SQLite MBTiles (файл `PACKS/{pack_id}.bin`). Сравниваются географические координаты WGS84; поддержан crossing antimeridian.
- Ответ — JSON-массив записей из `catalog.json`; при отсутствии покрытия — `[]`. Невалидные записи пропускаются; координаты вне допустимого диапазона получают HTTP 422.
- Добавлено 3 теста: покрытие Алматинского региона, неверные границы, антимеридиан.
- Версия iOS исходников: `2.4.1 (25)`.

## Ограничения

- `bounds` MBTiles — прямоугольник охвата, не реальная геометрия покрытия тайлов. Обнаружение пакета не гарантирует, что конкретный тайл существует.
- Не подтверждено автоматическим тестом соответствие кода закрытого/дополненного GitHub-репозитория, так как проверялся локальный архив v2.4 с реализованным здесь маршрутом.
- Полная компиляция Xcode и IPA пока не проверена.

## Локальные проверки

`python -m pytest -q server/tests` → **34 passed** (в данной среде).

## Как применить

Лучше загрузить весь архив в корень GitHub (обязательно сохранить `.github/`). Если на GitHub есть ваши собственные изменения после v2.4, не заменяйте их молча: перенесите `server/app.py` (добавленный endpoint), `server/tests/test_point_packs.py` и изменения версии вручную через сравнение файлов.

После коммита запустите GitHub Actions. Проверки сервера должны перейти к следующему этапу — сборке iOS. Если она упадёт, приложите полный лог шага `Compile iOS and package unsigned IPA`.
