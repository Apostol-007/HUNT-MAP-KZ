# HUNT MAP KZ v1.4 — исправление наложения интерфейса

- Исправлена первопричина: `.ignoresSafeArea` больше не применяется к `mapTab` целиком, только к MapLibre-подложке.
- Заголовок, боковые кнопки, баннер и нижний dock находятся в safe area iPhone.
- Заголовок компактен, GPS и Online справа; отдельные боковые панели.
- Баннер загрузки резервирует высоту нижней навигации.
- По нажатию на незагруженную карту открывается диалог импорта/загрузки MBTiles.
- Поиск и погода в боковых кнопках пока являются переходами к существующим экранам (не отдельные полноценные сервисы).
- Проверка структуры Python пройдена; Xcode/iOS компиляция и проверка на iPhone здесь недоступны.
