# HUNT MAP KZ v2.5 — UI redesign in Freedom Bank style

## Что изменено

- Введена единая тёмная дизайн-система `FreedomBankTheme.swift`.
- Нижняя навигация переделана в стиле Freedom Bank: тёмная стеклянная панель, зелёный активный раздел, компактные иконки.
- Главный экран карты переделан:
  - полноэкранная карта остаётся фоном;
  - верхняя панель с названием приложения, GPS-статусом и ONLINE/OFFLINE;
  - быстрые действия для погоды и слоёв;
  - нижние кнопки GPS / Метка / Запись оформлены как карточки.
- Погодные экраны переведены в новую палитру: тёмный фон, зелёные акценты, карточки.
- Дополнительно затемнены и приведены к единому стилю экраны маршрутов, маркеров, животных, загрузок, диагностики и редактора меток.

## Что не менялось

- Логика GPS, треков, офлайн-карт, погодных слоёв и диагностики.
- Серверная часть и тесты API.

## Проверка

- `swift test` (Core): пройдено.
- `pytest server/tests`: пройдено.
- Полный Xcode/iOS build не выполнялся в этой среде и должен быть проверен в GitHub Actions / Xcode.
