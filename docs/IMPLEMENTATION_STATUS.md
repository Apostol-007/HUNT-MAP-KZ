# HUNT MAP KZ — состояние оптимизации 5.9.0 (64)
Дата: 24 ноября 2026 года.

## Граница проверенного
- Компиляция и упаковка IPA проверяются GitHub Actions отдельно от запуска на iPhone.
- Тесты Swift Core и Python проверяют вычисления, API и контрактные признаки исходников.
- Пока нет независимого инструментального подтверждения, что 5.9.0 не вылетает на конкретном iPhone, что PMTiles отображаются штатным MapLibre Native и что фоновые GPS/геозоны стабильно работают при заблокированном экране.
- Предыдущий подтверждённый успешный релиз: 5.8.2 (63), workflow 45325455430. Новая версия должна пройти собственный релизный workflow.

## Реализовано в исходниках 5.9.0
1. **GPS и данные:** активные координаты записываются в append-only SQLite (TrackPointJournal.swift); резервная запись полного JSON при недоступности журнала. Старый field.json сохраняется и читается без потери существующих треков, маркеров и зон. После прерывания запись восстанавливается из SQLite, затем консолидируется в JSON. В меню «Ещё» есть экспорт полной резервной копии.
2. **Запуск и диагностика:** MapLibre создаётся только при открытии вкладки «Карта»; стартовая синхронизация не блокирует экран, тяжёлое хеширование вынесено из главного потока. LaunchHealth фиксирует время до состояния готовности и обнаруживает незавершённый предыдущий запуск, не собирая GPS.
3. **Офлайн-файлы:** проверка SHA-256 дорожных пакетов и PMTiles выполняется вне UI. Сохраняются квитанции успешной проверки SHA с ревизией файла и сроком периодической перепроверки. Парсинг дорожных GeoJSON и импорт охотугодий выполняются в detached-задачах.
4. **MBTiles:** локальный read-only HTTP-сервер переиспользует SQLite-connection для установленных растровых пакетов вместо повторного открытия на каждом запросе тайла.
5. **Карта:** сравнение геометрии аннотаций выполняется через Hasher по координатам вместо генерации больших строк описания массивов. Отдельные погодные слои не блокируют жесты карты.
6. **Навигация:** резервный расчёт графа и маршрута выполняется вне UI. Отклонение измеряется до ближайшего сегмента пути, а не только до узлов. Перестроение дороги требует трёх последовательных значимых отклонений с учётом GPS accuracy. Для записанных маршрутов отклонение также измеряется до сегмента.
7. **Погода:** Open-Meteo отдает прогнозную сетку с быстрым/подробным разрешением, сохраняется кеш. При изменении часа старый прогноз остаётся с явной отметкой времени. Нулевые осадки обозначены отдельно от отсутствия данных. Старые файлы кеша очищаются в фоновой задаче, сохраняются последние 256.
8. **CI:** Linux verification на push; macOS IPA только через ручной запуск или коммит с [release]. Включено прерывание устаревших workflow, кеш pip и сканирование распространённых форматов секретов в текущем Git-дереве.

## Сохранили без функциональных потерь
- Офлайн-пакеты карт, ранее сохранённые MBTiles и PMTiles, геозоны, метки, треки, GPX, автоматические обновления.
- Valhalla и резервный дорожный граф, пешая/автомобильная навигация, воспроизведение и прохождение записанного пути в обоих направлениях.
- Три погодных слоя, погодный кеш и работа GPS без интернета.
- Проверку криптографических хешей при первичной установке и проверках по требованию/периодически.

## Не проверено или осталось отдельной инженерной задачей
- **Физический iPhone:** холодный старт после обновления, 8-часовой фоновый трек, watchdog/OOM, memory high-watermark. Это нельзя подтвердить одним успешным xcodebuild.
- **PMTiles в MapLibre Native:** стиль использует pmtiles://, но в репозитории нет подтверждённого тестом нативного обработчика этой схемы. До фактического чтения тайлов на iPhone нельзя отмечать слой работающим.
- **Полная декомпозиция MainView:** крупные блоки остаются в MainView; большой перенос состояния без XCTest/UI тестов несёт риск регрессии. Вынесена вычислительная геометрия, но UI-компоненты пока не переписаны полностью.
- **Офлайн-дорожный охват:** OfflineRoadOverlayStore ограничивает 1000 линий и 12000 вершин на viewport. Нужно перейти на пространственный индекс/векторные тайлы и проверить плотные регионы.
- **Скриншотные тесты погоды и iOS UI:** нужны Xcode Simulator / реальный iPhone и golden snapshot для ветра, давления и осадков.
- **Исторические секреты:** CI сканирует только текущие отслеживаемые файлы. Для публичного репозитория отдельно проверить полную историю Git и перевыпустить скомпрометированные ключи.
- **Границы угодий:** техническая загрузка не равна геодезической/юридической верификации данных.
- **Ресурсы и лицензии:** точность спутника 1 м/пиксель определяется легальностью и разрешением исходных данных, не наличием UI-переключателя.

## Критерии приёмки релиза
- Все Linux/Core/Python и security checks зелёные.
- Xcode Release build и IPA artifact успешно получены из того же релизного коммита.
- Приложение открывается после обновления поверх прежней установки без удаления user data.
- Сохранённый трек, маркеры, границы и офлайн-пакеты доступны после перезапуска.
- Погодные слои реально отображаются на карте; нулевые осадки не выглядят ошибкой.
- Расчёт маршрута и GPS-ведение не блокируют прокрутку экрана и не сбрасывают маршруты.
