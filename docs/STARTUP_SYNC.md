# HUNT MAP KZ · Стартовая синхронизация

## Что изменено

- При холодном запуске NWPathMonitor проверяет состояние подключения. Без доступной сети стартовый экран сразу закрывается, и остаются установленные офлайн-данные.
- При наличии сети обновляются статические каталоги на `https://create.web-works.kz/maps/`: `catalog.json` (MBTiles), `routing/catalog.json` (дорожная сеть), `zones/catalog.json` (охотугодья), `protomaps/catalog.json` (PMTiles) и `valhalla/catalog.json` (офлайн-роутинг).
- Скачиваются только отсутствующие или изменившиеся пакеты по контрольным суммам из каталогов. Загрузка проходит последовательно, с проверкой размера/SHA-256 и безопасной заменой файла после успешной проверки.
- Показываются этап, название текущего пакета, общий счётчик пакетов и процент; для поддерживающих частичный прогресс загрузчиков есть дополнительная полоска прогресса. Для непередающих данные о числе скачанных байтов отображается прогресс пакетов, а не фиктивный процент байтов.
- При проблемах с одним пакетом остальные обрабатываются, а старые версии сохраняются. Кнопка «Открыть приложение без ожидания» отменяет текущую задачу и открывает интерфейс.
- В стартовом экране ротируются 80 авторских коротких рекомендаций для туристов, рыбаков и охотников, упорядоченных по категориям. Файл: `iOS/HuntMap/StartupTips.json`. **40 000 подтверждённых уникальных советов пока не собрано**; формат позволяет расширять базу и принимать редакторски проверенные карточки.

## Источники образовательных рекомендаций

- U.S. National Park Service, Ten Essentials: https://www.nps.gov/articles/10essentials.htm
- U.S. National Park Service, Leave No Trace: https://www.nps.gov/articles/leave-no-trace-seven-principles.htm
- Hunter-ed, What You Learned: https://www.hunter-ed.com/pennsylvania/studyGuide/What-You-Learned/201039_111910/
- Take Me Fishing, Fishing Safety: https://www.takemefishing.org/how-to-fish/fishing-safety/fishing-safety-tips/

Советы перефразированы и служат общим образовательным материалом, не являются цитатами. Законы, сезонные ограничения охоты/рыбалки и зоны безопасности в Казахстане необходимо сверять с местными официальными источниками.

## Правила хостинга

Пакеты должны быть перечислены в соответствующих JSON-каталогах с корректными SHA-256, размерами, путями и типами. Наличие произвольного файла на FTP/хостинге без записи в каталоге не делает его автоматически загружаемым. Для PMTiles загружаться могут только корректные v3-архивы; для Valhalla требуется `valhalla_tiles.tar` с манифестом `hunt-valhalla-v1`.

## Ограничения и проверки

- Подключённый Wi-Fi/сотовый интернет не гарантирует доступность хостинга. При недоступности сервера загрузка пропускается по ошибке, не удаляя локальные карты.
- Первый старт с полным Казахстаном может потребовать много свободного места и трафика. На экран добавлена возможность пропустить процесс.
- Прогресс больших PMTiles по байтам зависит от существующего загрузчика и может не обновляться, пока скачивается файл; это не означает остановку.
- Старые установленные Valhalla-пакеты без маркера версии могут потребовать однократной загрузки для перехода на проверку версий.
- Для подтверждения стабильности необходимо успешное выполнение GitHub Actions (Swift Core, серверные тесты и сборка iOS) и пробная установка на реальном iPhone.
