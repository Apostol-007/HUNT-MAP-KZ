# HUNT MAP KZ v2.3 — погодная карта и управление временем

## Изменения

- Обновлена панель погодных слоёв: русская временная шкала 0–48 ч, шаг 1 час, отдельные +/- и явная кнопка загрузки.
- Добавлены легенды для ветра (км/ч), давления на уровне моря (гПа), прогнозных часовых осадков (мм/час).
- Повышена строгость проверки гридов: координаты всех узлов должны соответствовать сетке, время ответа — запрошенному часу, отрицательные скорости/осадки запрещены.
- Запросы сетки теперь на 4×4 узла (9 визуализируемых ячеек), без искусственной интерполяции за пределами зоны.
- Показано точное время загруженного прогноза и предупреждение об устаревшем кэше. Слайдер сам по себе не выдаёт старые данные за новое время: пользователь нажимает «Загрузить».
- Сохранены русские подписи карты и полноэкранная компоновка.

## Ограничения

- Настоящих изобар, анимированных частиц, радарных осадков пока нет.
- Для сетки требуется отдельно развернуть HTTPS FastAPI сервер. Без него доступен точечный прогноз.
- Не подтверждены компиляция полной iOS-цели, карта на iPhone и работа погодных слоёв на устройстве.
- Государственные слои охотугодий Tabigat не интегрированы как официально подтверждённый feed.
- Имеющиеся тесты Swift-ядра не компилируют SwiftUI/MapLibre целиком.
