# HUNT MAP KZ 1.5.4 — несколько каталогов офлайн-карт

## Изменено
- В существующем экране «Загрузки» добавлены три сохраняемых HTTPS-профиля каталога MBTiles.
- Переключение активного профиля и проверка URL без встроенных учётных данных.
- Используется существующий контракт `/v1/packs/manifest` и `/v1/packs/{pack_id}` с HTTP Range и SHA-256.
- Установленные карты не удаляются при переключении источника.
- Версия проекта обновлена до 1.5.4 (154).

## Ограничения
- Профили не содержат вымышленных или нелицензированных серверов. Пользователь должен указать действующий совместимый HTTPS-сервис.
- Не реализована автоматическая генерация MBTiles из произвольного прямоугольника карты.
- Не реализована загрузка тайлов Google/Яндекс, для которой нужны соответствующие права.
- Реальные слои егерей, охотугодий и животных требуют подтверждённых геоданных.
- iOS-компиляция и физическое устройство не проверены.
