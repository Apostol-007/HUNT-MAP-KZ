# HUNT MAP KZ v0.4 — MapLibre offline integration

Дата: 19.11.2026. Статус: исходники / без сборки Xcode и реального iPhone.

## Изменения
- MapKit убран из картографического UI. Добавлена зависимость MapLibre Native iOS через SwiftPM/XcodeGen (>=6.31.0, <7.0.0).
- Локальный JSON-стиль без сетевых источников, шрифтов, sprites. Если нет локальной карты — пустой тёмный фон; нет подмены на онлайн.
- Растровые MBTiles добавляются через `MLNRasterTileSource` с локальным `mbtiles://` URL. Источники подключаются после загрузки стиля и обновляются при смене реестра.
- GPS, маркеры, границы и трек отображаются аннотациями MapLibre. Непроверенные границы отделены подписью и цветом.
- Добавлен импорт локального MBTiles через системный Files picker; контроль формата, SHA-256, копирование и реестр, без загрузки на сервер.
- Исходные возможности HTTP Range, проверка SHA-256 и установка с сервера сохранены.

## Ограничения и риски
- **НЕТ** сборки через Xcode и подтверждения корректности iOS API: среда Linux. Изменения интерфейса не подтверждены компилятором iOS.
- **НЕТ** физического iPhone, GPS-сессии на заблокированном экране, тестов энергопотребления и сетевого trace.
- Прочитанная документация MapLibre Native подтверждает поддержку MBTiles/PMTiles в современных сборках, но именно связка версий и схема `mbtiles://` должна пройти тест на реальном устройстве.
- Local import не подтверждает лицензию загруженной пользователем карты.
- Нет реальных подтверждённых границ охотугодий РК, нет спутниковой детализации 1 м/пиксель, официальных данных по видам и тропам.
- Нет полноценной дедупликации на уровне тайлов, подписанных манифестов, защищённой синхронизации и production инфраструктуры.
- Source-level тесты только предотвращают случайное возвращение сетевого fallback; **не доказывают** отсутствие сетевого трафика от SDK.
- Для воспроизводимого production билда нужен `Package.resolved` после теста на macOS/Xcode.

## Проверка на macOS
1. Установить Xcode, XcodeGen и платформенные инструменты SwiftPM.
2. `cd iOS && xcodegen generate`.
3. Открыть `HuntMapKZ.xcodeproj`, дождаться загрузки SPM MapLibre. Выполнить сборку и исправить возможные различия SDK API.
4. Подключить тестовый файл `.mbtiles` с лицензией на offline использование. Убедиться, что карта рисуется без сети.
5. В авиарежиме проверить панорамирование, перезапуск, import/удаление пакетов, геозоны, запись трека.
6. Снять сетевой trace и проверить, что рендер карты не делает запросов к внешним ресурсам.

Это промежуточная разработка, не готовый App Store/TestFlight релиз.
