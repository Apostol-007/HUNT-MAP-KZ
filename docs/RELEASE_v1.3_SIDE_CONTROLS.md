# HUNT MAP KZ 1.3 — боковые элементы управления

- Полноэкранная карта сохранена.
- Верхний статус уменьшен, кнопки GPS, метки и записи вынесены вправо.
- Маршруты, слои, животные и загрузки вынесены влево.
- Нижняя панель остаётся плавающей и не изменяет высоту карты.
- Нажатие на карту вне геозоны при отсутствии установленных MBTiles предлагает загрузку.
- Диалог не имитирует скачивание: переводит в существующий раздел настройки HTTPS-сервера, поиска пакетов и импорта MBTiles.
- При наличии хотя бы одного установленного пакета приложение пока не определяет географическое покрытие отдельной точки: это ограничение текущей версии.
- iOS-сборка требует проверки в GitHub Actions/Xcode; локально на Linux компилятор iOS недоступен.
