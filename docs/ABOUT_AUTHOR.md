# Автор и инициатор HUNT MAP KZ

**Николай Олегович Мякшин**, Алматы, Казахстан.

Профессиональная специализация: руководство направлением мониторинга и Observability, инфраструктурный мониторинг, техническая эксплуатация и системы аналитики.

Идея HUNT MAP KZ: сделать удобный офлайн-навигатор для охотников Казахстана с безопасной GPS-записью, проверяемыми границами охотничьих территорий, маркерами, обменом координатами, предупреждениями и актуализируемыми сведениями о животных.
