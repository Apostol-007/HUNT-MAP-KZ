# HUNT MAP KZ — v0.6 (19.11.2026)

## Фактически внесённые изменения

- Сервер: `server/wildlife.py` проверяет структуру публичного JSON-каталога, отклоняет неизвестные поля (включая координаты), дубли, ошибки дат и URL. Никакие внешние источники автоматически не скачиваются.
- Публикация разрешённых каталогов вручную: `python -m server.wildlife examples/wildlife-schema-example.json --id demo-v1` (из корня проекта). Пример содержит синтетические данные, не реальные наблюдения.
- API: `GET /v1/wildlife/manifest?ground_id=...`, `GET /v1/wildlife/packs/{pack_id}`. На скачивании проверяются размер и SHA-256, поддерживается ETag и 304.
- iOS: `WildlifeUpdater.swift` получает список версий по указанному пользователем HTTPS-серверу, скачивает пакет по явному нажатию, валидирует SHA-256, метаданные и применяет локально атомарно. HTTP разрешён лишь для локального 127.0.0.1 (разрешение ATS в проекте не настроено).
- Экран «Животные»: поля адреса сервера и ID территории, проверка обновлений и кнопка скачивания.
- Установка не означает юридической/научной верификации источника и не подтверждает права охоты.

## Тесты

- Сервер: `python -m pytest -q server/tests` — **10 passed** (в этой среде).
- Swift Core: `cd Core && swift test -q` — **12 XCTest + 8 Swift Testing = 20 прошли** в среде Linux.
- **iOS код не собирался в Xcode и не тестировался на iPhone.** В частности, новая UI-интеграция не проверена компилятором iOS, а выполнение файловых операций и ATS на устройстве не подтверждено.

## Как запустить

```bash
python -m pip install -r server/requirements.txt pytest httpx
python -m server.wildlife examples/wildlife-schema-example.json --id demo-v1
uvicorn server.app:app --host 127.0.0.1 --port 8000
```

Проверить `http://127.0.0.1:8000/v1/wildlife/manifest?ground_id=DEMO-NOT-LEGAL`. На реальном iPhone `127.0.0.1` указывает на сам телефон; для сетевого сервера используйте HTTPS-адрес, доступный с iPhone.

## Известные ограничения

- Нет проверенной реальной базы животных Казахстана: нет GBIF/iNaturalist ETL, таксономического слияния, разрешений на массовую выдачу наблюдений, модерации и регуляторных статусов.
- Пакеты имеют SHA-256, но **нет криптографической подписи доверенного издателя**. Подменённый сервер способен выдать согласованные манифест и файл. Для производственного использования необходимы подписи и закреплённый публичный ключ в iOS.
- Обновления запускаются только вручную; нет автоматического расписания, очереди синхронизации, возобновления загрузки wildlife и ограничения HTTP-ответа на уровне потока до загрузки данных в память (проверяется только итоговый размер).
- На iOS не зафиксирована работа с реальным SDK MapLibre, отсутствие сетевых обращений, запись в фоне и поведение GPS-предупреждений.
- Нет официально подтверждённых границ, лицензированного покрытия 1 м/пиксель и готовых карт РК.

Не считать релиз готовым навигатором для охоты и не использовать синтетические полигоны в качестве правовых границ.
