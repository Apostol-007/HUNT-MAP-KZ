# HUNT MAP KZ v1.5.3 — проверка покрытия выбранной точки

## Реализовано
- При нажатии на карту проверяется покрытие выбранных координат установленными растровыми MBTiles.
- Границы считываются из `metadata.bounds` (WGS84: west,south,east,north). Отсутствующие или некорректные bounds не считаются подтверждением покрытия.
- Поддержаны пересекающие 180-й меридиан bounding boxes.
- Добавлен прямой переход к импорту локального MBTiles из диалога выбранной точки.
- Текущая компоновка экрана не менялась.

## Ограничения
- Проверка по bounding box не гарантирует наличие конкретного тайла в любой точке прямоугольника.
- Без заранее опубликованного пакета и настроенного HTTPS-сервера нельзя скачать произвольный участок автоматически.
- Нет встроенных массовых загрузчиков тайлов Google, Яндекс или публичного OSM.
- Реальные границы охотугодий, егери и каталоги животных должны поступать из разрешённых проверенных источников.
- Компиляция iOS на macOS и тест на физическом iPhone не проводились.
