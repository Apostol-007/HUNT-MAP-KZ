# HUNT MAP KZ 1.5 (Build 15) — статус реализации

## Изменено в коде
- Онлайн-подложки OpenFreeMap Liberty / Bright / Positron (требуют интернет).
- Строгий офлайн через ранее импортированные растровые MBTiles; карта доступна для ручного просмотра без GPS.
- Переключатели слоёв: границы, метки (включая машину и вручную сохранённые точки егерей), GPS, выбранный записанный маршрут.
- Кнопка «Машина» сохраняет текущие GPS-координаты. Без GPS новую позицию машины получить нельзя.
- Кнопка «Центр» центрирует по GPS, а если его нет — по сохранённой машине или первой метке.
- Выбор маршрута в истории для отображения на карте, включая возможность визуально возвращаться по линии маршрута без сети.
- Google Maps и Яндекс Карты открываются как внешние сервисы. Не реализовано незаконное/неавторизованное скачивание тайлов.

## Не реализовано
- Встроенный Google/Yandex SDK и их офлайн-загрузка: требуются договорные права и отдельная интеграция.
- Автоматическое скачивание произвольного участка Казахстана без своего сервера пакетов и лицензированных данных.
- Пошаговое ведение по маршруту и расчёт обратного пути; пока доступно визуальное следование по сохранённой линии.
- Автоматические координаты егерей, офлайн-покупка путёвок и координатные ареалы животных: нет проверенных источников и данных.
- Автоматическое создание точки машины без GPS: пользователь может открыть сохранённую точку, но не получить новую координату без источника позиционирования.

## Проверки
- Swift Core tests (Linux): 14 XCTest + 8 Swift Testing, прошли.
- Проверка статической компоновки проекта: выполнена.
- Компиляция iOS/MapLibre и тест на iPhone: НЕ ПРОВЕДЕНЫ (нет Xcode/macOS).
- Лицензии: OpenFreeMap online — не использовать массовое скачивание тайлов. Google/Yandex — только внешние ссылки.
