# HUNT MAP KZ — PATCH v4.2: управление метками на карте

Дата: 23.11.2026

## Базовая версия

**v4.1 поверх v4.0**. Патч содержит только новые/изменённые файлы по существующим путям репозитория. Не является полным проектом.

## Изменённые файлы

- `iOS/HuntMap/OfflineMapView.swift`: распознавание нажатия и долгого нажатия на карту, выбор имеющейся метки, обработка координаты, пользовательская иконка/цвет маркеров, связь с SwiftUI через callbacks.
- `iOS/HuntMap/MainView.swift`: диалог установки метки по координатам; открытие карточки существующей метки; перенос метки на новую точку по нажатию; сохранение в FieldModel; отдельное действие просмотра угодья при нажатии на область.
- `iOS/HuntMap/FieldModel.swift`: создание метки по произвольным валидным координатам, не зависящее от GPS-фикса, и запись в локальное хранилище.
- `iOS/HuntMap/MarkerEditor.swift`: поддержка сценария новой метки без действия удаления (существующий редактор сохранён).
- `iOS/HuntMap/MapMarkerDetails.swift` (НОВЫЙ): карточка метки, редактирование, перенос, переход на карте, копирование координат, системная отправка, построение внешнего маршрута в Apple Maps, удаление с подтверждением.

## Удаляемые файлы

Нет.

## Сценарии для теста на iPhone

1. Откройте Карту, нажмите на пустое место → «Поставить метку» → появится карточка метки; после закрытия метка видна на карте.
2. Долгое нажатие на пустое место → то же меню с координатами; можно отменить без сохранения.
3. Нажмите на существующую метку → карточка с действиями.
4. Измените название, вид значка, цвет, координаты → сохраните → откройте метку снова и проверьте изменения.
5. «Переместить на карте» → нажмите на новое место → координаты метки изменились. Отмена режима не меняет координаты.
6. Поделиться, скопировать координаты, построить маршрут в Apple Maps, удалить с подтверждением.
7. В области угодья нажатие предлагает «Информация об угодье» и «Поставить метку».
8. После принудительного закрытия и перезапуска метка и её новые координаты должны сохраниться.
9. Проверить обычную панораму, зум, GPS, запись маршрута и офлайн-пакеты на регрессии.

## Проверки в текущей среде

- `swiftc -frontend -parse iOS/HuntMap/*.swift` — успешно (синтаксис, НЕ iOS typecheck).
- `python scripts/check_ui_structure.py` — успешно.
- Swift Core `swift test -q` — 24 XCTest и 11 Swift Testing пройдены.
- `python -m pytest -q server/tests` — 34 теста пройдены.

## Не проверено

Полная сборка Xcode (`xcodebuild`), соответствие MapLibre Swift API на целевой версии и поведение жестов на реальном iPhone. Доступная Linux-среда не содержит iOS SDK; о готовности IPA утверждать нельзя.

## Установка

Распаковать ZIP в корень репозитория поверх **v4.1**, сохранить каталоги, заменить файлы, выполнить `.github/workflows/ios-unsigned-ipa.yml`, проверить лог сборки и провести тесты на устройстве.
