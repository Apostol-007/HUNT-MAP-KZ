# HUNT MAP KZ v4.6 — встроенный HTTPS-хостинг и офлайн-каталоги

**База:** v4.5.2 (с применённым iOS-кодом v4.5); отдельные патчи v4.5.1 и v4.5.2 меняли Windows-часть.

## Изменения

- Публичный адрес HTTPS **уже встроен в Swift-код**: `https://create.web-works.kz/maps/`. Никакой ввод адреса, FTP-логина или пароля на iPhone не нужен.
- Читает `catalog.json`, `routing/catalog.json`, `zones/catalog.json` с указанного хостинга.
- Сохраняет подтверждённо разобранные каталоги карт и зон в Application Support (ранее локально сохранялся только каталог маршрутов).
- При недоступности сервера сохраняет отображение последнего успешно загруженного каталога вместо очистки списка карт и зон.
- FTP-пароль остаётся **только** в локальном Windows `hosting_config.json`; не копируйте его в приложение или GitHub.

## Состав патча

- `iOS/HuntMap/HostingOfflineDownloads.swift` — изменён.
- `PATCH_README.md` — этот единый файл документации.
- **Удаляемые файлы:** нет.

## Установка

Распаковать ZIP в корень проекта поверх v4.5.2 с заменой файла, сохраняя дерево каталогов. Изменения **не** предназначены для загрузки отдельным ZIP-файлом в корень GitHub. После обновления исходников пересобрать IPA через GitHub Actions.

## Ограничения

- Каталог кэшируется, но уже скачанные файлы карт/дорог сохраняются своим механизмом. Кэш каталога **не означает**, что все его пакеты скачаны на iPhone.
- Первая загрузка каталога требует интернет и реального доступного HTTPS-адреса. Если каталоги не опубликованы, приложение не должно выдавать пакеты за установленные.
- Установку пакетов и маршрутизацию необходимо проверить на реальном iPhone. Сквозная маршрутизация через несколько регионов и фоновая загрузка больших карт пока не подтверждены.
- Полная компиляция Xcode и сетевое подключение к пользовательскому хостингу здесь не проверялись.

## Выполненные проверки

- `swiftc -frontend -parse` для Swift-файлов: успешно.
- Программная сверка: встроенный URL и названия всех трёх каталогов присутствуют, `hosting_config.json` не включён в ZIP.
