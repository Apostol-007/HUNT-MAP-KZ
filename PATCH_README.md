# HUNT MAP KZ — PATCH v4.3: исправление интерактивных меток

**Дата:** 23.11.2026  
**База:** полностью применённые v2.5 → v3.0 → v3.1 → v4.0 → v4.1 → v4.2.  
**Формат:** только изменённые файлы в оригинальной структуре GitHub, без полного исходного архива.

## Суть исправления

1. `iOS/HuntMap/OfflineMapView.swift` — совместное распознавание одиночного/долгого тапа с жестами MapLibre; корректный поиск пользовательской метки в пределах 28 pt от касания; **стабильные аннотации по UUID**. Прежде каждый вызов `updateUIView` удалял и заново создавал все маркеры, чем сбивал распознавание нажатий. Изменения значка, цвета, заголовка или координат заменяют только изменённый маркер; другие маркеры не трогаются. Свой значок SF Symbols и выбранный hex-цвет рисуются в MapLibre. GPS отображается отдельно от пользовательских меток. Географические границы, GPX и погода сохраняются отдельными аннотациями.
2. `iOS/HuntMap/MainView.swift` — новая метка **сначала редактируется**, затем сохраняется; кнопка «Метка» больше не создаёт безымянную стандартную метку при нажатии; сохраняется прежняя карточка действий по нажатию на сохранённую метку.
3. `iOS/HuntMap/FieldModel.swift` — `insertMarker(_:)` сохраняет ровно один полностью оформленный Marker и не дублирует UUID.
4. `scripts/check_ui_structure.py` — обновлена проверка существования GPS/маршрутных действий с учётом замены старой вставки на `insertMarker`.

## Как пользоваться

- **Один тап** по свободному месту карты → «Поставить метку» → редактор имени, иконки и цвета → «Сохранить» → маркер с выбранными параметрами на той же координате.
- **Долгое нажатие** → выбор точки и тот же процесс.
- **Тап по метке** → управление: редактировать, переместить на карте, показать на карте, копировать координаты, поделиться, открыть внешний маршрут, удалить с подтверждением.
- **Перенос** → в карточке «Переместить на карте», затем тап на новом месте. Отмена не меняет координат.
- После закрытия и открытия приложения проверить сохранение формы и цвета.
