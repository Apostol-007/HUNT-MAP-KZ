# HUNT MAP KZ — PATCH v4.1 (GPS TRACK RELIABILITY)

Дата: 23.11.2026

## Базовая версия
Применять **поверх v4.0**, установленной после v2.5 → v3.0 → v3.1. Этот архив содержит только изменённые файлы, структура путей соответствует репозиторию GitHub.

## Изменённые файлы
- `iOS/HuntMap/FieldModel.swift`
  - Восстановление незавершённого трека после закрытия приложения **один раз**: после восстановления сохранённое поле `pendingTrack` очищается, дублирование по `id` не допускается.
  - При старте/остановке записи и паузе сбрасывается последняя GPS-точка для исключения скачков между сессиями.
  - Отклоняются GPS-фиксы с точностью хуже 100 м, устаревшие и пришедшие из будущего (>5 с).
  - Пауза не срабатывает без активной записи.
  - GPX содержит высоту (`ele`) при конечном значении и ISO 8601 UTC timestamp с миллисекундами.
  - Добавлена вычисляемая длительность сохранённого маршрута.
- `iOS/HuntMap/MainView.swift`
  - В карточке маршрута отображаются расстояние, количество точек, длительность.

## Удаляемые файлы
Нет.

## Как применить
1. В GitHub открыть репозиторий, в котором уже применён патч v4.0.
2. Распаковать архив; заменить файлы по указанным путям, сохраняя структуру директорий.
3. Запустить существующий workflow `.github/workflows/ios-unsigned-ipa.yml`.
4. На iPhone протестировать: запись → пауза → продолжить → завершить → экспорт GPX; затем принудительно завершить приложение при записи и проверить однократное восстановление маршрута после двух перезапусков.

## Проверки в текущей среде
- `swiftc -frontend -parse`: прошёл для обоих изменённых Swift-файлов.
- Swift Core: 24 XCTest + 11 Swift Testing пройдены.
- `python scripts/check_ui_structure.py`: успешно.
- `python -m pytest -q server/tests`: 34 теста пройдены.

## Не проверено
- Полная компиляция Xcode на macOS (`xcodebuild`) и запуск IPA на реальном iPhone: macOS/iOS SDK в текущей среде отсутствуют.
- Геозоны в фоне при закрытом экране и корректность GPX на реальном GPS-датчике.
- Соответствие всех восьми экранов pixel-perfect эталону, лицензии и данные всех картографических слоёв.

## Ограничения
- Время маршрута: разница между первым и последним принятыми GPS-фиксами; паузы входят во временной интервал. Это **не** «чистое время движения».
- Для уведомлений и записи GPS при заблокированном экране требуются соответствующие разрешения iOS и проверка фактической работы на устройстве.
