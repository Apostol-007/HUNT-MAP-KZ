# HUNT MAP KZ — v4.4 IN-APP OFFLINE ROUTING PATCH

**База:** полностью применённые v2.4.3 → v2.5 → v3.0 → v3.1 → v4.0 → v4.1 → v4.2 → v4.3.  
**Назначение:** убрать вызов Apple Maps из карточки метки; выполнять навигацию внутри HUNT MAP KZ.

## Что изменено

- `iOS/HuntMap/MapMarkerDetails.swift`: действие «Маршрут внутри HUNT MAP KZ» вместо перехода по `maps.apple.com`.
- `iOS/HuntMap/MainView.swift`: выбранная метка становится целью навигации; карта остаётся активной, появляется панель цели, расстояния и азимута, завершение навигации, импорт локальной сети GeoJSON, переключение режимов.
- `iOS/HuntMap/OfflineMapView.swift`: собственная линия текущего маршрута (голубая), без стороннего навигационного приложения.
- `Core/Sources/HuntCore/OfflineRouting.swift` (новый): построение кратчайшего пути A* по связанной сети LineString/MultiLineString GeoJSON. Сеть обрабатывается **на устройстве** без сетевых запросов.
- `Core/Tests/HuntCoreTests/OfflineRoutingTests.swift` (новый): тесты развилки, разрыва сети и ограничения привязки.
- `iOS/project.yml`: номер версии 4.4.0, build 44.

## Работа навигации

1. На карте нажать существующую метку → «Маршрут внутри HUNT MAP KZ».
2. Без локальной сети доступен **«Азимут»**: соединение GPS и цели прямой линией (НЕ дорожный маршрут). Расстояние и направление по GPS обновляются. Это НЕ маршрут для следования по дорогам и НЕ гарантия проходимости.
3. Чтобы строить путь **по тропам**, импортировать `.geojson` из файлов iPhone через кнопку «Импорт сети». Требуется GeoJSON `FeatureCollection`, где геометрии — `LineString` / `MultiLineString`, координаты `[долгота, широта]`, WGS84. Вершины соседних линий соединяются, если совпадают после округления до 6 знаков. Для перекрёстков нужны общие вершины (node intersections); простое визуальное пересечение линий не создаёт соединения.
4. Устройство сохраняет импортированный файл в `Application Support/routing/network.geojson`. Повторное открытие приложения восстанавливает сеть.
5. Если начало или цель удалены от ближайшей вершины более 250 м либо компоненты не соединены, движок **не рисует вымышленную дорогу** и сообщает причину. Можно явно переключиться на «Азимут».
6. Кнопка × завершает навигацию. Запись GPS-трека работает отдельно.

**Важно:** существующие MBTiles, растровые/векторные тайлы, стили MapTiler и каталог охотугодий НЕ являются маршрутизируемой дорожной сетью. Нужен отдельный дорожный граф из законно полученных данных OSM/собственных троп. В этом патче граф импортируется вручную; автоматическая подготовка покрытия всего Казахстана пока НЕ реализована. Поиск пути предполагает двустороннее движение и не учитывает запреты/покрытие/перепады/рельеф; его нельзя считать безопасным автомобильным навигатором. Нет голосовых указаний, turn-by-turn, динамического перепрокладывания по GPS, офлайн-генератора графа из OSM PBF.
