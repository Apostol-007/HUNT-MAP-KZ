# HUNT MAP KZ — v4.7 iOS Offline Navigation Manager

**Базовая версия:** v4.6 поверх v4.5.x / v4.4. Установить файлы поверх репозитория, сохраняя пути. Это **патч**, не полный проект.

## Изменённые файлы

- `iOS/HuntMap/HostingOfflineDownloads.swift` — поиск по каталогам дорожных сетей, фильтр отсутствующих, счётчик обработанных пакетов, остановка массовой загрузки, кэш проверенных MBTiles-частей, пропуск установленных сетей и зон, удаление зон, выбор нескольких соседних графов для маршрута.
- `Core/Sources/HuntCore/OfflineRouting.swift` — конструктор сети из набора GeoJSON, связывание по совпадающим вершинам WGS84 с точностью 1e-6 градуса; без фиктивных рёбер.
- `Core/Tests/HuntCoreTests/OfflineRoutingMultiPackTests.swift` — тесты связанной и разорванной сети.

**Удаляемые файлы:** нет.

## Настройки и загрузки

Адрес HTTPS зашит: `https://create.web-works.kz/maps/`. Каталоги: `catalog.json`, `routing/catalog.json`, `zones/catalog.json`. FTP-пароль отсутствует в iOS.

- Кэш частей MBTiles хранится в `Application Support/routing/hosting/verified-chunks`. SHA-256 проверяется при каждом использовании. При прерывании **завершённые части** повторно не скачиваются; докачка с середины отдельной части (HTTP Range) пока не реализована.
- «Остановить после текущего файла» останавливает очередь на границе файлов/пакетов; сетевой запрос в процессе может закончиться. Уже установленные файлы сохраняются.
- Несколько дорожных пакетов выбираются по прямоугольному коридору старт–цель с запасом 0.03 градуса. Они объединяются по общим координатным вершинам. Лимит существующего движка 200000 вершин сохраняется. Если генератор обрезал линии на границах без общих вершин, между ними не будет маршрута. Длинные маршруты по всей стране, повороты, перепрокладка и ограничения проезда ещё **не реализованы**.
- Фильтр показывает дорожные пакеты по имени/ID. Пакеты по-прежнему перечислены сеткой (не областями): каталог генератора пока не предоставляет административные регионы.
- MBTiles импортируются через ранее существующий `OfflineTileStore`. Удаление установленных MBTiles выполняется существующим менеджером карт, не этим экраном.
- Импорт GeoJSON-зон не подтверждает юридические границы охотугодий.

## Проверка

- `swiftc -parse` для трёх Swift-файлов — успешно.
- Linux Swift smoke test: соединение двух пакетов по общей вершине, отсутствие искусственного пути для разорванных пакетов — успешно.

## Проверки после сборки iOS

1. Открыть «Офлайн с хостинга» и обновить каталоги; проверить имена пакетов и количество дорожных сетей.
2. Найти пакет по ID, скачать, перезапустить приложение, убедиться, что он установлен.
3. Запустить загрузку всех недостающих пакетов, остановить и возобновить. Уже скачанные части MBTiles не должны передаваться повторно.
4. Импортировать и удалить тестовую зону, убедиться в корректном обновлении полигона на карте.
5. Проверить маршрут по двум соседним пакетам с общими вершинами, затем случай без связи.
6. Проверить отказ в разрешении GPS, отсутствие сети, недоступность хостинга, недостаток памяти и длительные загрузки.
