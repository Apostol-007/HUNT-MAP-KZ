# HUNT MAP KZ v4.8 — удаление старого UI и ремонт офлайн MBTiles

**База:** v4.7, применённая поверх всех предыдущих версий.

## Исправлено
1. Полностью удалены устаревшие экраны `LegacyMainView.swift`, `MapDownloadAndLayers.swift`, старый менеджер `OfflineAreaPacks.swift`. Ссылки и кнопки на них удалены, нужный `GroundDetailsSheet` перенесён в отдельный файл.
2. Растровая подложка подключается через существующий локальный сервер `LocalMBTilesServer` (`127.0.0.1`) и tile URL templates MapLibre вместо неподдерживаемого прямого `mbtiles://`.
3. После запуска loopback-сервера MapLibre повторно подключает локальные источники тайлов.
4. После импорта MBTiles режим подложки переключается на офлайн; в менеджере есть явный переключатель «Онлайн-подложка».
5. Современный менеджер показывает отличие растровой карты MBTiles от дорожной сети GeoJSON и поддерживает импорт MBTiles из файлов iPhone.
6. Номер версии установлен на 4.8.0 (build 48). Обновлены старые тесты, которые требовали наличие `LegacyMainView` и фиксированной версии 4.0.

## Удалить из Git репозитория (ОБЯЗАТЕЛЬНО)
- `iOS/HuntMap/LegacyMainView.swift`
- `iOS/HuntMap/MapDownloadAndLayers.swift`
- `iOS/HuntMap/OfflineAreaPacks.swift`

Можно запустить `APPLY_PATCH_WINDOWS.bat` в корне репозитория **после распаковки патча**, либо выполнить удаления в GitHub вручную. Если старые файлы останутся, проверка `scripts/check_ui_structure.py` завершится ошибкой. Просто загрузить ZIP как файл на GitHub недостаточно: его надо распаковать и применить изменения.

- **Xcode build и проверка реального iPhone не выполнены**; это не подтверждённая IPA-сборка.

## Ограничения
- Публикация `routing/catalog.json` обеспечивает GeoJSON дорог, но НЕ растровые карты. Чтобы получить офлайн-подложку, необходимо отдельно опубликовать лицензированные MBTiles и совместимый `/maps/catalog.json` со ссылками на чанки, либо импортировать MBTiles через «Файлы» на iPhone.
- Для маршрутизации между несколькими пакетами и построения путей сохраняются ограничения текущего движка.
- Если в GitHub уже применены дополнительные пользовательские изменения, сравните файлы перед заменой.
