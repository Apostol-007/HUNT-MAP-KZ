# HUNT MAP KZ v0.7 — сборка неподписанного IPA с Windows

## Что подготовлено

Файл `.github/workflows/ios-unsigned-ipa.yml` выполняет: тесты HuntCore и Python API, установку XcodeGen на **облачном macOS**, генерацию проекта `iOS/HuntMapKZ.xcodeproj` из `iOS/project.yml`, разрешение локальной зависимости `../Core` и внешней MapLibre, сборку iOS (`iphoneos`, `Release`) без подписи, проверку `.app`, упаковку в `Payload/HuntMapKZ.app` и публикацию артефакта `HUNT_MAP_KZ_unsigned_IPA`.

**Важно:** workflow создан и проверен статически, но реальная macOS/iOS компиляция пока не запускалась; совместимость конкретной версии MapLibre и iOS API не подтверждена. Полученный IPA будет **неподписанным** и не устанавливается напрямую на iPhone.

## Как запустить на Windows

1. Создайте **приватный** репозиторий на https://github.com/new. Скопируйте в корень репозитория **содержимое каталога `HUNT_MAP_KZ_MVP`**, а не вложенную папку целиком. В корне должны оказаться `iOS/`, `Core/`, `server/`, `.github/`.
2. Откройте GitHub → репозиторий → **Actions**. Включите Actions, если предложено. Для приватного репозитория проверьте доступность macOS runner и лимит минут на вашем тарифе.
3. Выберите **HUNT MAP KZ - unsigned iOS IPA** → **Run workflow** → запустите.
4. Дождитесь окончания jobs `verify`, `ios` со статусом success. Если `ios` упал, откройте лог конкретного шага, а также скачайте `ios-build-log` при наличии.
5. Откройте завершённый workflow → **Artifacts** → `HUNT_MAP_KZ_unsigned_IPA` → скачайте ZIP артефакта GitHub, распакуйте его на Windows. Внутри будет `HUNT_MAP_KZ_unsigned.ipa`.
6. Скачайте Sideloadly только с https://sideloadly.io/. Подключите iPhone по USB, доверьтесь компьютеру, выберите IPA в Sideloadly и используйте свой Apple Account для подписи/установки. Установка зависит от разрешений Apple, совместимости IPA и ограничений бесплатного аккаунта. Не указывайте пароль Apple в GitHub Actions, репозитории, issue или документации.
7. Если запросит iOS, разрешите профиль разработчика и включите Developer Mode. Установленное с бесплатной подписью приложение обычно необходимо обновлять каждые **7 дней**.

## Если сборка падает

- **`No such module 'MapLibre'` / package resolution**: сверить имя продукта и совместимость MapLibre `maplibre-gl-native-distribution` с XcodeGen/выбранным Xcode, при необходимости обновить `iOS/project.yml` по документации версии SDK.
- **`xcodegen generate`**: изучить `iOS/project.yml`; проект генерируется в `iOS/`, запускать из этой папки.
- **Swift compile error**: использовать строку ошибки и путь в логе `Build for physical iPhone without signing`; успешные `swift test` в Core **не доказывают**, что SwiftUI/MapLibre собираются.
- **IPA есть, Sideloadly не устанавливает**: сохранить точную ошибку. Проверить бесплатные entitlements и ограничения подписи; фоновые GPS-права проверять на устройстве отдельно. Не пытаться выдавать unsigned IPA за подписанный.
- **Нет кнопки Run workflow**: workflow должен быть в default branch (`main`) и Actions должны быть разрешены.

## Ограничения текущего MVP

Нет официально проверенных границ угодий, лицензированных офлайн-карт 1 м/пиксель, юридической проверки данных и подтверждённых полевых испытаний. Даже после успешной компиляции GPS-фон, уведомления о пересечении границ, автономность MapLibre и совместимость бесплатной подписи необходимо испытывать отдельно на физическом iPhone. Не использовать MVP как единственный навигационный или юридический источник во время охоты.
