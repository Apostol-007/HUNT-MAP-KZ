# GitHub / IPA на Windows

1. Создайте пустой репозиторий `HUNT-MAP-KZ` на GitHub.
2. Распакуйте **содержимое** ZIP в корень репозитория: `.github`, `iOS`, `Core`, `server`, `docs`, `README.md`.
3. Коммит и Push в `main`.
4. Перейдите в `Actions` → `iOS unsigned IPA` → `Run workflow`.
5. После успешной сборки скачайте artifact `HUNT-MAP-KZ-unsigned-IPA` и журнал `ios-build-log`.
6. Unsigned IPA нельзя считать готовым для обычной установки: подпись и установка на физический iPhone требует соответствующего способа подписи. Бесплатный личный Apple Account и сторонняя подпись имеют ограничения и срок действия; TestFlight/App Store требуют оплачиваемую программу.
7. Если Actions завершился с ошибкой, передайте `ios-build-log` для точечного исправления. До успешной сборки и тестов не используйте приложение для соблюдения границ охоты.
