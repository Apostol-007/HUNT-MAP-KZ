# HUNT MAP KZ v1.0 — полноэкранная карта и карточки угодий

## Изменено
- Карта занимает весь экран над системной вкладкой, без отступов и заголовка; кнопки находятся поверх карты.
- Тап внутри полигона открывает карточку хозяйства, включая **все скалярные поля** `properties` GeoJSON (например: «Название», «Площадь, га», «Пользователь», «Постановление государственного органа», «контакты»). Поля не подменяются вымышленными значениями.
- Значения импортированных полей сохраняются локально вместе с границами.
- Неизвестные данные и юридический статус отмечаются как неподтвержденные.

## Tabigat.gov.kz
Публичная интерактивная карта подтверждена; документированный разрешенный endpoint GeoJSON/WFS для слоя «Охотничьи хозяйства» **не установлен**. Не встроены недокументированные запросы или обход доступа. Для живых данных требуется легальный GeoJSON-экспорт либо официально разрешённый WFS/ArcGIS REST endpoint. Меню «Загрузки» → «Импортировать границы GeoJSON» поддерживает его.

## Проверка
Тесты Swift-ядра и серверные тесты могут запускаться в CI. Полную компиляцию iOS/MapLibre и нажатие на полигоны следует проверить GitHub Actions и реальным iPhone.

## Известные ограничения
Не входит полный реестр официальных угодий РК, нет доказательства прав на републикацию, нет гарантии GPS при принудительном завершении приложения; спутниковые карты 1 м/пиксель не включены.

## Direct HTTPS import
В «Загрузки» добавлен URL прямого GeoJSON (`FeatureCollection`/`Feature`). Подходят только сервисы, явно предоставляющие данные в GeoJSON и разрешающие их использование. Если государственный слой предоставляет WFS, сначала получите допустимый GeoJSON-URL по официальной документации этого сервиса. Не подставляйте ссылку на страницу `https://tabigat.gov.kz/ru`: это HTML-сайт, а не GeoJSON.

## Операции
1. На iPhone откройте «Загрузки» → «Загрузить GeoJSON напрямую», укажите HTTPS URL файла.
2. Нажмите «Загрузить границы» и дождитесь статуса.
3. Перейдите на «Карта» и нажмите внутри загруженного полигона.
4. В карточке доступны исходные поля и метка о неподтвержденной юридической актуальности.

## Доказательные ограничения
Полигон «Манул» и приведённые в запросе значения — пример желаемого вида карточки, **не загруженный набор из Tabigat**. Не помещён в production dataset.
