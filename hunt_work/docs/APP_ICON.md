# HUNT MAP KZ — App Icon

Иконка подключена в `iOS/HuntMap/Assets.xcassets/AppIcon.appiconset/AppIcon.png` (1024×1024, RGB без прозрачности).

`iOS/project.yml` содержит `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon`. При генерации Xcode-проекта через XcodeGen каталог ресурсов должен попасть в target автоматически, поскольку `HuntMap` входит в `sources`.

Порядок: `cd iOS && xcodegen generate`, открыть `.xcodeproj`, собрать и установить приложение заново. Если iOS показывает прежний значок, удалить старую версию приложения с устройства (предварительно сохранить пользовательские данные) и установить новую.

Проверка сборки и отображения значка на физическом iPhone ещё не выполнялась. В архиве не исправлены проблемы карты и аварийного завершения записи GPS.
