# HUNT MAP KZ v0.5 — Offline Wildlife Catalog

Дата: 19.11.2026. Статус: исходники прототипа, **не собранное iOS-приложение**.

## Изменения
- В `HuntCore` добавлены `WildlifePack`, `WildlifeTaxon`, `WildlifeValidator`.
- Формат JSON v1. Жёсткий список допустимых полей: точные координаты, геометрия и иные незадокументированные поля запрещены в публичной карточке вида. Ограничение размера 8 MiB, максимум 10000 записей.
- Требуются явные источник, HTTPS URL, лицензия, дата, ID угодья и научное имя. Поддерживаются 4 статуса доказательности, защита от дублей ID.
- В iOS добавлен локальный `WildlifeStore`: импорт через Files, сохранение без серверных вызовов, загрузка после повторного запуска и удаление.
- Экран «Животные» показывает виды, статус, дату наблюдения и источник, фильтрует по трём вариантам имени.
- `examples/wildlife-schema-example.json` демонстрирует структуру **вымышленными** данными и не является реальной фауной Казахстана.

## Ограничения
- Нет официального пакета охотугодий РК, геометрии с юридическим подтверждением, реальных сведений о животных, спутниковых снимков 1 м/пиксель.
- Валидация файла **не подтверждает** достоверность авторства, лицензии, наблюдения или юридического статуса. Источник только отображается.
- JSON-файлы импортируются вручную, автоматический GBIF/iNaturalist ETL отсутствует; нет подписи манифеста и контроля доверенного издателя.
- SQLite-схема wildlife, серверная синхронизация, атомарная замена импортированных пакетов и агрегирование по границам пока не реализованы.
- Загрузка карт по API существует как прототип; тестов сети/офлайн на iPhone не было.

## Далее
1. Сборка в Xcode c зафиксированными зависимостями и исправление возникающих ошибок компиляции.
2. Реальные правомерные векторные карты и подтверждённые границы, GIS ingest и проверки геометрии.
3. Подписанные версии пакетов wildlife, безопасный ETL с источниками GBIF/iNaturalist и модерацией, без раскрытия чувствительных наблюдений.
4. Полевые испытания офлайн-режима, GPS и уведомлений на физическом устройстве.
