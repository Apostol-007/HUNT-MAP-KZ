# HUNT MAP KZ v1.2 — iPhone viewport + launch fix

## Исходная проблема
Скриншот: карта занимает не весь дисплей, оставляя чёрные полосы. Диагностический отчёт показывает `0.9.0`, потому что это **жёстко заданная строка в коде**, а не доказательство установленной версии.

## Изменения
- Устранена ссылка XcodeGen на отсутствующий `HuntMap/Info.plist`.
- Включена генерация корректного Info.plist, добавлен полноэкранный LaunchScreen.storyboard и `UILaunchStoryboardName`.
- Версия устанавливается из `MARKETING_VERSION=1.2.0` и `CURRENT_PROJECT_VERSION=12`.
- Отчёт диагностики читает версию из собранного приложения и выводит размеры дисплея/окна и safe area.
- Workflow выполняет проверку исходной конфигурации и проверяет Info.plist собранного .app.

## Как тестировать
1. Загрузить все файлы архива в GitHub, включая `.github` и `scripts`.
2. Запустить Actions → iOS unsigned IPA, убедиться в успешном шаге Verify generated Info.plist.
3. Подписать и установить именно новый IPA. Если система оставила прежнюю программу, сделать резервную копию личных данных перед удалением старой версии.
4. Открыть карту; убедиться, что нет полос. Встряхнуть iPhone; версия должна быть `1.2.0 (12)`; в отчёте есть размеры `Screen pt`, `window pt`, `safe area`.
5. Прислать отчёт и скриншот при сохранении проблемы.

## Честный статус
Изменение исправляет очевидную ошибку project.yml и конфигурацию запуска, которая может приводить к letterboxing. Без реального Xcode/iPhone теста **нельзя утверждать**, что экран уже отображается на 100% правильно. Сборка unsigned IPA не означает возможность установки без подписи.
